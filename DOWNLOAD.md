# Download EDR Viewer for Mac

**The downloadable release is being prepared.** A direct application download will be added here after publication and verification.

## Which file do I need?

| File | What it is |
| --- | --- |
| **Mac app ZIP or DMG** | The application — choose this to install EDR Viewer |
| Matching source ZIP | Application source for developers and license compliance |
| SHA256SUMS.txt | File integrity checksums |
| RELEASE_NOTES.md | Changes and installation notes |
| GitHub “Source code (zip/tar.gz)” | This distribution repository, not the Mac application |

The currently prepared candidate supports **Apple Silicon (M1 or later), macOS 14+**. It is a test build and is not Apple notarized. The final recommended version, filename and size will be shown with the direct download.
