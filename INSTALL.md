# Install on your Mac

1. Download the Mac application from the [download page](DOWNLOAD.md).
2. Open the DMG and drag the app into **Applications**, then eject the image.
3. Open EDR Viewer from Applications. **Viewer Mode** works without activation.

## Opening the Live edition

This locally signed Live edition is not Apple notarized. If macOS blocks it, first confirm the file came from this project's release and that you trust it. Follow Apple's [Open Anyway guidance](https://support.apple.com/en-gb/102445). Do not disable macOS security globally.

## Updating

Keep a copy of the previous app until you have checked the new version. Close EDR Viewer before replacing it in Applications. Your recordings are separate files; retain your own backups.

2.18 stores Live licenses separately from test licenses. Test keys and saved test authorizations cannot unlock it. Keep the test edition and its Keychain records. Activate your Live key online in 2.18. macOS may request Keychain permission; a fixed number of dialogs is not promised.
