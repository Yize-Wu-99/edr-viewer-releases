# Install on your Mac

1. Download the Mac application from the [download page](DOWNLOAD.md).
2. For ZIP: unzip, then move the app into **Applications**. For DMG: open the disk image and drag the app into **Applications**, then eject the image.
3. Open EDR Viewer from Applications. **Viewer Mode** works without activation.

## Opening a test build

The currently prepared test build is not Apple notarized. If macOS blocks it, first confirm the file came from this project's release and that you trust it. Follow Apple's [Open Anyway guidance](https://support.apple.com/en-gb/102445). Do not disable macOS security globally.

## Updating

Keep a copy of the previous app until you have checked the new version. Close EDR Viewer before replacing it in Applications. Your recordings are separate files; retain your own backups.

A changed test-build signature can require access to a previous saved license. Initial migration may involve macOS item-access and application-identity checks. This is separate from the first-open security check; a fixed number of dialogs is not promised.
